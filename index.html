Comandos Git y GitHub útiles

Guía personal de comandos de Git y GitHub, con una explicación breve de qué hace cada uno y cuándo usarlo.

1. Configuración inicial de Git

Antes de empezar a trabajar con Git, es necesario configurar algunos datos que permitan identificar quién realiza los cambios en un proyecto. Esta configuración se hace una sola vez por computadora, ya que Git la guarda y la utiliza en todos los repositorios en los que trabajemos.

Configurar nombre y correo electrónico

Cada vez que guardamos un conjunto de cambios mediante un commit, Git registra quién lo realizó. Para eso, debemos configurar nuestro nombre y correo electrónico: 

git config --global user.name "Tu Nombre"
git config --global user.email "tu-email@ejemplo.com"

El nombre y el correo que configuremos quedarán asociados a nuestros commits, permitiendo identificar al autor de cada modificación.

Establecer main como rama principal

Cuando creamos un repositorio nuevo, Git necesita definir cuál será su rama inicial. Con el siguiente comando podemos establecer main como nombre predeterminado, utilizando el mismo criterio que GitHub: 

git config --global init.defaultBranch main

De esta manera, cada vez que inicialicemos un repositorio nuevo, su rama principal se llamará main automáticamente.

Verificar la configuración

Si queremos comprobar que nuestro nombre quedó configurado correctamente, podemos ejecutar: 

git config --global user.name

Git nos devolverá el nombre que guardamos. De la misma manera, podemos verificar nuestro correo electrónico: 

git config --global user.email

Estos comandos nos permiten consultar la configuración sin modificarla.
