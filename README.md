# Comandos Git y GitHub útiles

Página web con los comandos principales de Git y GitHub, explicados de forma simple para quienes recién se están iniciando. Nació como una guía personal de consulta mientras aprendía a trabajar con control de versiones, y la organicé para que también le sirva a otras personas que están empezando.

## Contenido actual

- **Configuración inicial:** cómo configurar nombre, correo y la rama principal `main`.
- **Trabajo individual:** el flujo de trabajo diario (`status`, `add`, `commit`, `push`) y buenas prácticas para trabajar sola o solo.
- **Trabajo en equipo:** el flujo con ramas (GitHub Flow), Pull Requests, merge, buenas prácticas y cómo resolver conflictos.
- **Otros comandos útiles:** consultar ramas, ver el historial con `git log` y comparar cambios con `git diff`.

## Cómo usar

**Ver la página online:** [luisimuller.github.io/comandos-git-github](https://luisimuller.github.io/comandos-git-github/)

**Verla en tu computadora:**

1. Cloná el repositorio:

   ```bash
   git clone git@github.com:luisimuller/comandos-git-github.git
   ```

2. Abrí el archivo `index.html` en tu navegador.

Desde el índice de la barra superior podés saltar directamente a cada sección.
